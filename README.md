# Тестовое задание сисадмина

## Что где лежит

- network/ — статический IP и VLAN
- ssh/ — вход по ключу
- vpn/ — WireGuard
- proxmox/ — виртуализация
- video-link.txt — ссылка на видео

## Как все устроено

Сервер: Ubuntu Server в VirtualBox, IP 192.168.0.200.

Сеть:
- статический IP 192.168.0.200/24
- VLAN 10 — 10.10.10.2/24
- VLAN 20 — 10.10.20.2/24

Удаленный доступ:
- SSH по ключу ed25519, пароль отключен
- WireGuard, сервер 10.0.0.1, клиент 10.0.0.2

Виртуализация:
- Proxmox VE 9.2.2
- ВМ test-vm внутри Proxmox с Ubuntu Server

Подробности в файлах внутри каждой папки.
