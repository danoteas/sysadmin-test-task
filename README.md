## 1. Сеть

На сервере настроен статический IP и два VLAN-интерфейса на одном физическом адаптере.

**Статический IP**

- Интерфейс: enp0s3
- Адрес: 192.168.0.200/24
- Шлюз: 192.168.0.1
- DNS: 8.8.8.8, 1.1.1.1

**VLAN**

| Интерфейс | VLAN ID | IP-адрес |
|-----------|---------|----------|
| enp0s3.10 | 10 | 10.10.10.2/24 |
| enp0s3.20 | 20 | 10.10.20.2/24 |

VLAN нужны, чтобы разделить одну физическую сеть на изолированные сегменты. Это повышает безопасность, уменьшает broadcast-трафик и упрощает управление.

Детали: [network/network.md](network/network.md)  
Конфиг: [network/netplan.yaml](network/netplan.yaml)

## 2. Удалённый доступ

**SSH по ключу**

- Сгенерирован ключ ed25519 на Windows
- Публичный ключ добавлен в authorized_keys на сервере
- Вход по паролю отключён

Детали: [ssh/ssh.md](ssh/ssh.md)  
Конфиг: [ssh/sshd_config](ssh/sshd_config)

**WireGuard VPN**

| Параметр | Сервер | Клиент |
|----------|--------|--------|
| IP | 10.0.0.1/24 | 10.0.0.2/24 |
| Порт | 51820 | — |
| AllowedIPs | 10.0.0.2/32 | 10.0.0.0/24 |

На сервере включён IP forwarding и MASQUERADE для выхода в интернет.

Детали: [vpn/vpn.md](vpn/vpn.md)  
Конфиги: [vpn/wg0-server.conf](vpn/wg0-server.conf), [vpn/wg0-client.conf](vpn/wg0-client.conf)

## 3. Виртуализация

Установлен Proxmox VE 9.2.2 в VirtualBox (nested virtualization).  
Создана VM test-vm с Ubuntu Server 24.04.

Параметры VM:
- RAM: 1024 MB
- CPU: 1 core (kvm64)
- Диск: 8 GB (local-lvm, SCSI)
- Сеть: VirtIO, bridge vmbr0

Детали: [proxmox/description.md](proxmox/description.md)
