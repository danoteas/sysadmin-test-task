# Настройка сети

## Статический IP

Файл /etc/netplan/00-installer-config.yaml

Настройки:
- Интерфейс enp0s3
- IP 192.168.0.200/24
- Шлюз 192.168.0.1
- DNS 8.8.8.8 и 1.1.1.1

Применил через sudo netplan apply.

## VLAN

Сделал два VLAN на одном интерфейсе enp0s3:

- enp0s3.10 — VLAN 10, IP 10.10.10.2/24
- enp0s3.20 — VLAN 20, IP 10.10.20.2/24

Проверка:
- ip -br a
- ping 10.10.10.2
- ping 10.10.20.2

Все работает.

## Зачем VLAN

VLAN разделяют одну физическую сеть на несколько логических.
Это нужно для безопасности, чтобы трафик разных отделов не смешивался.
Еще это уменьшает broadcast-трафик и упрощает управление сетью.
