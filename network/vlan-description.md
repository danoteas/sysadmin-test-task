VLAN позволяет разделить одну сеть на несколько частей. 
Во первых, оно нужно для безопасности. Трафик разных разделов не должны быть в одной большой сети. 
Во вторых, если бы не было влан, broadcast трафик был бы большим, с большой нагрузкой на сеть.
Также, возможность расставления приоритетов разным влан сегментам. Например для камер voip должны быть отдельный влан, с чуть большим приоритетом трафика.
Трафик одной влан не должен быть виден другой.
